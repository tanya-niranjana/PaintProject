# Paint
Final Project for CS 250. Built in Java using JavaFX

Features
- Open and saves images
- Save as in different image formats
- Multiple tabs
- New blank image
- Line, square, rectangle, circle, ellipse, triangle, diamond, star, and polygone tools,
- Pencil and eraser
- Text tool
- Color picker and grabber
- Line width slider
- Dashed Outlines
- Undo and Redo
- Select, copy, paste, and move
- Rotte images 90, 180, and 270
- Flip images horizontally and vertically
- Rotate and flip selected areas
- Autosave
- Autosave countdown
- Windows Autosave notification
- Web server
- Drawing tools with icons
- Keyboard Shortcuts
- User Action logging

Requirements 
- JDK 26
- JavaFX SDK 26.0.2

Running the Program
This project can be run through netbeans

The jar file can also be run from the command line using:
java --module-path "C:\path\to\javafx-sdk-26.0.2\lib" --add-modules javafx.controls,javafx.graphics,javafx.swing -jar Paint.jar


Keyboard shortcuts:
- Ctrl + N - New
- Ctrl + O - Open
- Ctrl + S - Save
- Ctrl + Shift + S - Save as
- Ctrl + Z - Undo
- Ctrl + Y - Redo
- Ctrl + Q - Exit
